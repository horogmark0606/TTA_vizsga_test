# Curriculum index

One line per topic: `topic-id | project (card file), …`. Topic ids match `questions/index.yaml`.
Card files (`curriculum/<module>/<week>.md`) describe each project at concept level: what to understand,
pitfalls, explain-your-own-code prompts. Open only the ONE card file of the project you want to point to.
Projects themselves (descriptions, starter and reference code) are NOT in this repo; students have them.
