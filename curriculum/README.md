# curriculum/

Holds the course's projects as a map, not the projects themselves.
- `INDEX.md`: topic -> projects that practise it, with each project's card file. The only file the agent reads by default.
- `mN-<module>/<week>.md`: one **project card** per project (concepts to understand, typical pitfalls,
  explain-your-own-code prompts, related question ids). Concept level only.
- No project descriptions, tasks, starter or reference code live here. Students have the projects;
  the cards let the agent say "revisit project X, look at how you did Y".
