# Live-coding drill
**When:** the interview has a live-coding part.
**Scenario:** if `scenario` is set in the profile, use that scenario's tasks and time budgets instead.
**Steps:** 1) Give a small task (10-20 min) matching the stack. Never use a course project as the task. 2) Student thinks aloud: clarify, plan, code, test. 3) Agent stays silent except for clarifying questions; one hint if stuck 3+ min. 4) Debrief: communication, approach, edge cases, then code quality.
**Persist:** task, outcome and one improvement in the session note.
