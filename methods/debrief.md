# Post-interview debrief
**When:** after the trial tech interview (or any real interview).
**Steps:** 1) Ask: which questions were asked, how it felt, what was hard. 2) Write `progress/interviews/YYYY-MM-<name>.md`. 3) Offer to add missed questions to the bank via the `extend` skill (as "general, not course-reviewed"). 4) Adjust scores and set next focus topics in `progress/plan.yaml`.
**Persist:** interview file, new questions, updated `topics.yaml` and `plan.yaml`.
