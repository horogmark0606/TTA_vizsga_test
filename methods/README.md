# Practice methods

Each method is one short file the agent can follow. Add yours with the `extend` skill.
The agent loads a method file only when it uses that method.

| Method | File | When |
|---|---|---|
| Mock interview | (the `interview` skill) | Test knowledge under realistic conditions |
| Check my answer | check-my-answer.md | You paste your own workbook answer; agent says what's covered and what's missing, without writing it for you |
| Explain my project | explain-my-project.md | Practise explaining your own project code and decisions |
| Teach-back | teach-back.md | You explain a concept as if to a colleague; agent asks naive questions |
| Rapid fire | rapid-fire.md | Warm up, find gaps quickly |
| Live-coding drill | live-coding.md | Practice thinking aloud while coding |
| Post-interview debrief | debrief.md | After a real interview, turn it into learning |

Format of a method file: **When to use / Steps for the agent / What to persist.**
